# 🌸Flower Shop Website

A responsive Flower Shop Website built using HTML5 and CSS3. This project showcases a modern flower shop landing page with a clean user interface and a fully responsive design.

## ✨ Features

- Responsive Navigation Bar
- Hero Section
- About Section
- Product Showcase
- Customer Reviews
- Contact Form
- Footer Section
- Mobile-Friendly Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
